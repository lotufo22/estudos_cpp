# 📘 Estudos de C++

Repositório com os meus estudos de **C++**: exercícios, exemplos e pequenos projetos criados durante o aprendizado da linguagem. O objetivo é registrar a evolução, servir de material de consulta e organizar o que estou aprendendo.

> ⚠️ Este é um repositório de estudo. Os códigos podem conter erros ou soluções que ainda serão melhoradas.

## 🎯 Objetivo

- Praticar os conceitos da linguagem C++ na prática
- Manter um histórico organizado do que já foi estudado
- Ter uma base de consulta rápida para revisões futuras

## 📂 Estrutura do repositório

```
.
├── README.md
├── .gitignore
├── 01-fundamentos/        # variáveis, tipos, entrada/saída, operadores
├── 02-controle-de-fluxo/  # if/else, switch, laços (for, while)
├── 03-funcoes/            # funções, sobrecarga, recursão
├── 04-ponteiros-e-memoria/# ponteiros, referências, alocação dinâmica
├── 05-poo/                # classes, herança, polimorfismo
├── 06-stl/                # vector, map, set, algoritmos
└── projetos/              # pequenos projetos que juntam vários conceitos
```

Cada pasta contém arquivos `.cpp` nomeados de forma descritiva (por exemplo, `ponteiro_basico.cpp`) e, quando fizer sentido, um `README.md` próprio com um resumo do tema.

> A lista de pastas acima é uma referência e vai crescendo conforme o estudo avança.

## ▶️ Como compilar e executar

É necessário ter um compilador C++ instalado (como o **g++**). Exemplo:

```bash
# compilar
g++ -std=c++17 -Wall -Wextra arquivo.cpp -o programa

# executar (Linux/macOS)
./programa

# executar (Windows)
programa.exe
```

## 🛠️ Ferramentas utilizadas

- Linguagem: C++ (padrão C++17 ou superior)
- Compilador: g++ / GCC
- Editor: VS Code
